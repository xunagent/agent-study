# 故障恢复与保护边界

## 正常恢复

重跑相同命令，或按照 `daily` 的返回运行 `resume <operation>`。原始结构化草稿已在开始发布时写入云端运行记录，新设备不需要原本地文件。程序通过材料身份与版本找到同一操作，通过确定性标题和文件夹列表找回已创建文档，逐节恢复。已确认发布的章节不覆盖，用户正文编辑保持原样。

- **创建响应丢失**：先列目录，恰好找到一份则继续；找到多份停止并报告冲突。
- **创建结果不可见**：本地或云端存在创建意图时停止，不能盲目创建另一份。等待并核查目标目录；如果确实从未创建，人工检查记录后再清理对应意图，不自动删除文档。
- **图示导出失败**：保留已插入画板，修复权限/导出能力后重跑；不要重建整篇。
- **正文部分写入**：空节可以重试；已有内容与待写内容不一致时停止，保留双方供判断，不能整节覆盖。
- **索引失败**：运行 `sync` 或重复 `publish`，只补追加快照。
- **状态块删除或被替换**：不要搜索整篇替代。仅查看原状态范围/材料信息区域。用户选择互动小组件且无法回读点击结果时，保留组件，说明限制并运行 `use-manual-status`；用 `status` 记录用户明确确认的阅读进度。
- **通知失败**：重试通知，引用已建文档。不得调用 publish 来实现“重发”。

## 数据边界

云端运行记录保存配置、候选、材料身份、文档链接、发布阶段、阅读历史和并发声明；不保存密钥或个人感悟正文。本地目录中只有绑定、恢复标记、图示预览和宿主草稿，不能提交到公共仓库。云端运行记录是机器状态，不建议手工编辑。

文档展示标题不含内部编号。创建后将文档 ID 写入云端 `created` 事件，恢复优先按 ID 定位，支持用户改名。创建响应丢失时才用已记录的创建意图和精确标题核实；同名但无对应意图的文档不得擅自接管，找不到已知 ID 时也不得直接重建。图示源文件单独记录关联，其正文和生成历史可跨设备恢复。

普通 daily 只读系统文档和当前笔记的状态 block。主题回顾按指定章节读取学习正文。主动答疑才读取用户区域；不要通过整篇导出、检索全文或“先读取后过滤”绕过此约束。

## 并发与版本

本机使用 OS 文件锁；跨设备使用 30 分钟云端写入声明与释放记录，发现其他端未过期的写入声明则停止。声明依赖各设备时间和远端可见性，不是数据库事务或严格分布式锁，不能承诺跨设备 exactly-once。默认一个库只设一个自动端。

初始化过程尚无完整运行记录时只具备本机锁，不要从两台设备同时初始化。更新版本追加带版本号的章节，保留旧内容和阅读记录。对正文纠错默认追加勘误；需要改原段落时，先局部读取、比较用户编辑并解决冲突，不用 overwrite。

## 接口适配

`scripts/agent_study/lark.py` 是飞书适配边界。按照安装版本执行 `lark-cli skills read lark-doc references/lark-doc-fetch.md` 等查看接口。当前适配 XML `fragment`、块 id、revision、画板 token。schema/解析失败时输出可诊断错误，不把失败当空库，也不自动迁移文档格式。
